# 🌊 IRWA Marine Project

**Smart Ocean Navigation Assistant** for maritime professionals. Get real-time weather, AI-powered route planning, and hazard alerts — all in one vibrant, interactive app!

---

## 🚀 What Can You Do?

### 🏠 Dashboard
- 🌦️ See live marine weather and system status at a glance.
- ⚡ Quick links to all features.

### 🗺️ Weather Map
- 🗺️ Explore real-time weather on a beautiful interactive map.
- 🔍 Search for ports and locations.
- 👆 Click anywhere for instant weather details.

### 🧭 Route Analysis
- 🏁 Choose origin & destination ports.
- 🤖 Get AI-optimized routes, risk assessment, and weather along your journey.
- ⏱️ See estimated sailing times, distances, and hazard zones.

### 🤖 AI Chat
- 💬 Ask anything: "Is it safe to sail tomorrow from Colombo to Chennai?"
- 🧠 Get instant answers about weather, hazards, routes, and safety.
- 📏 Calculate distances and get route recommendations.

### ⚠️ Hazard Alerts
- 🚨 Monitor real-time hazards: storms, fog, tsunamis, and more.
- 📧 Set up email notifications for custom hazard thresholds.
- 📜 View alert history and manage your preferences.

### 👤 Profile & Authentication
- 🔐 Register and log in securely.
- 🛡️ Manage your account and alert settings.

## 🌈 How to Run

### 🐍 Backend
1. Create a Python virtual environment:
   ```powershell
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Copy `env.example` to `.env` and add your API keys.
3. Start the backend:
   ```powershell
   python start_backend.py
   ```

### ⚛️ Frontend
1. Go to the `frontend` folder:
   ```powershell
   cd frontend
   npm install
   npm run dev
   ```
